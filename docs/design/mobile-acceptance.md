# Мобильная приемка

Автоматические проверки выполняются на изолированной базе через
`scripts/check_auth_browser.py`.

Проверены страницы календаря, форм, профиля, CSV, групп и админки на ширинах
320, 360, 390, 430, 768 и 1280 px. Дополнительно проверены страницы при CSS zoom 200%
и форма на коротком экране 390×350. Горизонтального переполнения не обнаружено.
Русские имена с «ё» и emoji отображаются корректно; скриншоты сохранены в test-results.

Для переключения между полями моделируется сокращение visualViewport.
Найден и исправлен сбой: после focusout нижняя навигация возвращалась,
хотя клавиатура оставалась открытой. Теперь focusin пересчитывает ее видимость.

Эти проверки не заменяют приемку на физическом Android. Остаются:
реальная экранная клавиатура, touch-жесты, поворот устройства, системное увеличение
шрифта и работа через HTTPS на NAS. Этап ручной мобильной приемки пока открыт.

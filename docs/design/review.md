# Проверка реализации

Концепция: [concept.png](concept.png). Реальные снимки: [desktop.png](desktop.png),
[mobile.png](mobile.png), [form-mobile.png](form-mobile.png).

Встроенный Browser/IAB дважды завершился из-за Windows sandbox. Проверка выполнена
Playwright + установленным Edge в headless-режиме. Прямой view_image также отказал
из-за sandbox: изображения прочитаны через разрешенный файловый доступ и просмотрены
в разговоре. Концепция и реальные скриншоты сопоставлены визуально.

| Область | Сравнение и результат |
| --- | --- |
| Композиция | Открытое событие, крупная дата и хронологическая лента без сетки карточек |
| Типографика | Дата переведена с Georgia на Times New Roman для тонких штрихов; имя увеличено до 48/36 px |
| Выравнивание | Колонка даты расширена до 365 px, навигация приближена к бренду |
| Палитра | Теплый фон #FAF7F1, темный текст, зеленая кнопка и тонкие разделители; градиенты исключены по PLAN.md |
| Иконки | Локальные Bootstrap Icons, единый размер/штрих; бренд использует cake2 вместо нарисованного в концепции торта |
| Мобильный экран | Вертикальное событие, нижняя навигация и доступное добавление, safe-area и reduced motion |
| Текст | Основные заголовки, навигация, действие и имена из концепции сохранены в демонстрационном сценарии |

Проверены 1100×1000 и 390×1000 (соответствуют отдельным экранам концепции с учетом
рамки изображения), а также ширины 320/360/390/430/768/1280 и переход 900→901 px.
Форма требует вертикальной прокрутки; в конце формы сохранение доступно над
нижней навигацией. Длинные русские строки и неизвестный год не ломают сетку.
Проверены пять различимых групп компонентов, порядок текста первого экрана,
контраст базовых текстовых токенов, фокус и отсутствие горизонтального скролла.

Осознанные отличия: нет рамки доски макета, лишнего hamburger и градиента кнопки.
Реальный пустой календарь показывает пустое состояние вместо вымышленных людей.
Формы/настройки продолжают ту же систему; все новые кнопки ведут к рабочим действиям.

65 автоматических тестов и браузерный сценарий прошли: вход → приглашение →
отключение участника, а также добавление дня рождения → подтверждение → календарь.
Данные рабочего администратора не использовались. Подключен базовый путь создания;
редактирование, архив, удаление/перенос групп и CSV остаются этапом web-сценариев.

# HappyDay — согласованная визуальная система

Концепция: [concept.png](concept.png), создана встроенным Image Gen и одобрена пользователем.

Визуальный тезис: теплая бумага, открытая композиция и выразительная календарная дата.
Содержание: ближайшее событие → хронологическая лента → список → форма → настройки.
Взаимодействия: появление содержимого за 180 мс, отклик кнопки при нажатии,
раскрытие дополнительных форм. Reduced motion отключает движение.

Токены: фон #FAF7F1, текст #302C27, вторичный #70695F, акцент #365E49,
разделители #DED8CE, радиус 10 px. Segoe UI/system-ui для интерфейса,
Times New Roman / Georgia для дат и заголовков. Основной контейнер 1120 px с полями 40 px;
до 900 px — мобильная навигация, поля 24 px (20 px на 320 px).
Вместо сетки карточек используются открытые секции и строки с разделителями.

Локальные Bootstrap 5.3.8 и Bootstrap Icons 1.13.1 лежат в static/vendor.
Источники, SHA-256 и лицензии сохранены рядом. CDN во время работы не используется.
Иконки: cake2 (бренд), calendar2-week (ближайшие), people (список),
gear (настройки), plus-lg (добавить), chevron-right (открыть).
Формы используют общую сетку, Bootstrap form-control/form-select, понятные labels,
ошибки возле полей и серверную CSRF-защиту.

Концепция не содержит рабочих данных: демонстрационные записи создаются только
в отдельных тестовых базах. Реальный пустой календарь предлагает добавить первый
день рождения. Базовое добавление подключено к доменным правилам, чтобы
основное действие интерфейса работало. Полный CRUD и CSV относятся к следующему этапу.

Уточнения концепции: рамки макета не становятся рамками сайта; лишний hamburger
убран, поскольку все основные разделы доступны в нижней навигации.
Зеленая кнопка без декоративного градиента согласно PLAN.md.
При неизвестном годе возраст в главном событии не выводится.
Системная навигация не содержит фиктивных функций Telegram.
